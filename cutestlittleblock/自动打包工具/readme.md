这是来自cutestlittleblock的文件夹，主要用于上传一些弱智diy
关于如何使用这些弱智diy：

.py文件：
        I.最简单的方法：直接把该文件拖到和调用对象同一路径下，然后直接在调用对象文件内import即可
        II.如果你觉得写的还行想长期调用但懒得把文件拖来拖去的方法：
            Step1：创建一个文件夹dir，把你想长期调用文件file拖进dir。(设当前路径为D:\dir\file)
            Step2：开始菜单搜"编辑账户的环境变量">>用户变量新建>>变量名PYTHONPATH、值D:\dir
